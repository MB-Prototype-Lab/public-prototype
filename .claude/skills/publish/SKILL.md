Read docs/publishing.md and execute its resumable release procedure. Confirm ongoing study status with PMs alongside tracking choice; ask only when ambiguous. Frozen source tags and publication tags are separate. Publish only with explicit authorization. Retirement requires the explicit acknowledgement described in the procedure.

Read [the shared workflow](../../../docs/workflow.md) before acting. All paths in
that document are relative to the repository root. Remote actions follow the
[authorization boundary](../../../CLAUDE.md#collaboration). Report observed results,
not assumed remote success.

For a named Flow, follow [Prepare a Flow snapshot](../../../docs/publishing.md#prepare-a-flow-snapshot).
Preserve every retained snapshot identity and the procedure's separate review,
study/tracking decisions and publication authorization.
